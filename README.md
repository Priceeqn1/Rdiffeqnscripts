# Numerical validation for  
## *Homeostatic Turnover, Repair, and the Demographic Form of Haldane's Principle*

This repository contains the R code used for the numerical calculations and
Figure 1 in the manuscript:

**Ben Hardisty. _Homeostatic Turnover, Repair, and the Demographic Form of
Haldane's Principle._**

The code numerically validates the asymptotic and exact results derived in the
manuscript for a homeostatically regulated, damage-structured population with
reproduction-linked mutation and continuous repair.
